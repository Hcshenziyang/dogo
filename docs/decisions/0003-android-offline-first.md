# 0003：Android 首版复用界面，先完成本地工作台

日期：2026-10-16
状态：按用户确认的手机页面和 APK 要求实施；服务端连接后置。

采用 React + Capacitor 8，生成原生 Android 工程，APK 内置 Web 构建资源；不把在线网址套壳当安装包。
第一版保持收件箱、任务、设置三个入口。不引入项目管理、手机模型运行时或完整记忆浏览。

本地工作台默认为空，任务先进入持久化 outbox，明确未送达；演示沙盒有独立任务和草稿。
Android 私有存储使用受限 AtomicFile 桥接，写入成功后更新应用状态，并保留上一份备份。
系统备份/迁移默认关闭，凭据不进入快照。当前没有任何自动网络投递或个人文件扫描。

服务地址和信箱可预配置，但本版不读取令牌、不发网络请求。
后续通过 TaskGateway/MemorySyncGateway 接入，不允许把演示状态当成真实执行证据。
稳定 requestId 与创建时信箱用于后续幂等投递；切换服务/身份时的数据归属仍须在联网阶段明确。

Android 返回键、分享、复制、安全区由平台层负责。真实推送、后台唤醒、服务器身份与授权后续拉通。
APK 使用仓库外的本机私有签名密钥，不提交密钥或构建产物；只验证成功的构建才提供下载路径。

参考：[Capacitor 安装与资源打包](https://capacitorjs.com/docs/getting-started)。
