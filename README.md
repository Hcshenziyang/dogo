# DogO

DogO 的长期方向是个人助理。当前重新设计最小产品：统一备忘录与在线设备的远程 DSH 会话访问。

仓库已实现第一批 Python 后端：**FastAPI + SQLite + uv**，以及不包含 Agent 的最小 **Android 客户端**。启动、认证及设备投递协议见 [后端说明](server/README.md)，手机功能、构建和联调见 [手机端说明](mobile/README.md)；两个独立 DSH 插件的构建、安装和边界见 [插件说明](plugins/README.md)。旧源码、依赖、构建配置和文档已完整移到仓库外的本机归档；Git 历史仍保留，旧验收结果不计入新版。

当前组成：

- DSH 备忘录插件：桌面编辑入口、AI 工具、同步适配。
- DSH 远程访问插件：连接自有中转服务、操作本机原生会话，以及从电脑访问其他电脑的界面。
- 一个服务：备忘录存储与同步、个人设备登记、指定设备指令的持久投递、在线会话中转。
- 一个手机 App：首批提供登录、设备管理和备忘录入口；远程会话界面后置。

这里的两个插件是业务划分，每个插件都可以包含 DSH Host 与 Client 模块。服务器不运行 Agent，会话执行与持久化由原设备上的 DSH 负责。带指令的备忘录可在目标设备离线时入队，上线后自动投递；交互式远程会话仍要求目标设备在线。
