# 插件变更

## 0.2.6 · 2026-10-30 — 搜索框焦点样式修复

- 根据用户实际截图修复搜索框内外两层焦点边框重叠。原 `.dogo :focus-visible` 优先级高于旧搜索 input reset；现在仅在备忘录工具栏内明确清除 input 自身的边框、圆角、outline 和 shadow，防止通用/宿主输入样式干扰。
- 焦点指示统一交给搜索外框，保留键盘可见反馈；高对比模式保留系统 Highlight outline。搜索与新建按钮高度均为 38px。没有改搜索逻辑、卡片布局或写入保护。
- 两个共享插件升为 `0.2.6` 避免安装缓存。类型检查、51 项测试、构建与打包通过；包内版本和 host/client bundle 一致性已核对。
- 已查看用户反馈截图；新增测试覆盖作用域、reset 声明、统一焦点/高度和 CSS 解析，属于静态样式契约检查，不是宿主浏览器 computed-style/视觉验收。云端未重试此前被限制的浏览器启动，实际 DSH 修复后截图由本机验收提供。

## 0.2.5 · 2026-10-30 — 已确认的备忘录方格 UI

- 全宽方格代替分栏列表；首行搜索/新建/刷新/设置，第二行项目筛选/排序，编辑改为侧边抽屉。置顶暂不实现，无原型示例记录。
- 分类使用现有 `project`，保留 `category`/标签与附带指令；不变更 API、数据模型、后端或 Android。
- 草稿内容显示在卡片并参与已加载结果搜索，关闭/重开可恢复；本机存储失败保留页面内存输入并报错。原版本提交、待确认写入核对/重试和单击删除保持。
- 原生 inert 背景、键盘焦点循环与恢复、Escape、搜索 `/` 和编辑保存快捷键。窗口大小和主题适配已实现，尚未实际浏览器验收。

两个插件同步升至 `0.2.5`，避免同版本安装缓存沿用旧 bundle；共享样式由两包分别打包。

验证：`pnpm check`、48 项测试、`pnpm build`、`pnpm run pack` 通过，包内 manifest 版本均核对为 `0.2.5`；另外实际 Memos 组件的 React test renderer 合成回归通过（仅测试目录外临时依赖）。运行环境为 Node 24.22.1 / pnpm 11.25.0，不替代 README 要求的 Node 22+ / pnpm 9 与官方 DSH 验收。CSS 经 esbuild 解析通过。实际浏览器启动此前受执行沙箱限制，本轮未重试，未生成正式界面截图。未安装、部署或修改真实账户数据。

已加载记录的搜索/排序不是全量服务器搜索；项目 chips 也仅由已发现的服务器项目构成。本地草稿不是离线同步。插件需要本仓库当前 FastAPI API，不能与旧版 DogO 服务混用。
