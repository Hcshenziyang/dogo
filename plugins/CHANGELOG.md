# 插件变更

## 0.2.12 · 2026-11-05 — 精简备忘录卡片状态

- 卡片使用图标显示同步状态，冲突及未保存草稿保留提示；去除重复的新建卡片和底部统计，保留分页与同步异常提示。

## 0.2.11 · 2026-11-05 — 精简备忘录与会话引用

- 备忘录界面暂时隐藏项目、分类及标签的查看和编辑，保留原有字段和数据；设备指令及定时任务继续可用。
- DSH 会话的加号新增备忘录选项，选择已保存记录后以原生引用插入草稿；引用包含选中时的正文快照，不自动发送。

## 0.2.10 · 2026-11-05 — 本地优先备忘录

- 界面与 AI 工具共用持久本地备忘录，无需 DogO 登录；登录后下载并同步同一套记录，离线修改重连补同步，冲突保留副本并等待人工核对。
- 同步请求先落盘，按原请求恢复未知结果；计划及设备指令等待同步后交给服务。设备插件同步升级，以使用同一套断网时保留凭据的共享登录逻辑。
- 目标设备列表优先采用实时在线状态；网络不可用或响应缓慢时使用缓存，并标记状态未知。
- 隔离 DSH 0.2.2-rc.1、临时 FastAPI 和确定性测试模型验证界面、AI 工具、重启、离线/重连、冲突及定时/指令回归；真实账户及其他物理设备验收以 STATUS.md 为准。

## 0.2.8 · 2026-11-03 — 备忘录定时计划

- 新建/编辑备忘录可增加、修改、暂停或移除单次、每天、每周及每月执行计划；显示目标电脑、时区、下次触发和最近投递状态。默认北京时间，月末规则和离线合并由服务端执行。
- 保留立即指令、草稿、原请求重试及版本冲突保护；旧客户端普通更新不清除计划。更新计划需要先升级支持 `plan` 的 DogO 服务，设备插件沿用原接单通道。

## 0.2.7 · 2026-10-30 — 居中编辑与项目选择

- 根据确认的 V4 原型，将右侧编辑抽屉改为居中、有边界且可内部滚动的弹窗；保留关闭/返回焦点、键盘循环、草稿与写入保护。桌面搜索/新建/刷新/设置统一右对齐，窄屏换行；保留 0.2.6 搜索焦点修复。
- 项目支持下拉选择“未分类”/已加载项目，或输入新名称，保存备忘录时生效。旧 `category` 值仅在更多属性显示并原样保留，不新增分类模型或空项目管理。
- 新建未提交草稿仍可重开修改 AI 指令/目标电脑。已提交指令及已保存无指令记录明确显示当前 API 限制，不实现虚假的历史、重发或既有记录补发。
- 类型检查、54 项测试及构建/打包验证覆盖布局契约、选择/新项目及原字段保留、现有写入保护。实际浏览器验收使用同一正式组件与 mock control 的隔离宿主 fixture，不连接真实账户。父任务已通过点击/截图确认浅色桌面工具栏右对齐、搜索统一焦点、居中弹窗、项目输入及关闭/重开草稿恢复；最终深色截图确认紧凑居中、无重复项目 chip，辅助功能焦点确认新项目名称自动聚焦。这是合成宿主验收，不是已安装官方 DSH 或真实服务器验证。

## 0.2.6 · 2026-10-30 — 搜索框焦点样式修复

- 根据用户实际截图修复搜索框内外两层焦点边框重叠。原 `.dogo :focus-visible` 优先级高于旧搜索 input reset；现在仅在备忘录工具栏内明确清除 input 自身的边框、圆角、outline 和 shadow，防止通用/宿主输入样式干扰。
- 焦点指示统一交给搜索外框，保留键盘可见反馈；高对比模式保留系统 Highlight outline。搜索与新建按钮高度均为 38px。没有改搜索逻辑、卡片布局或写入保护。
- 两个共享插件升为 `0.2.6` 避免安装缓存。类型检查、51 项测试、构建与打包通过；包内版本和 host/client bundle 一致性已核对。
- 已查看用户反馈截图；新增测试覆盖作用域、reset 声明、统一焦点/高度和 CSS 解析，属于静态样式契约检查，不是宿主浏览器 computed-style/视觉验收。云端未重试此前被限制的浏览器启动，实际 DSH 修复后截图由本机验收提供。

## 0.2.5 · 2026-10-30 — 已确认的备忘录方格 UI

- 全宽方格代替分栏列表；首行搜索/新建/刷新/设置，第二行项目筛选/排序，编辑改为侧边抽屉。置顶暂不实现，无原型示例记录。
- 分类使用现有 `project`，保留 `category`/标签与附带指令；不变更 API、数据模型、后端或 Android。
- 草稿内容显示在卡片并参与已加载结果搜索，关闭/重开可恢复；本机存储失败保留页面内存输入并报错。原版本提交、待确认写入核对/重试和单击删除保持。
- 原生 inert 背景、键盘焦点循环与恢复、Escape、搜索 `/` 和编辑保存快捷键。窗口大小和主题适配已实现，尚未实际浏览器验收。

两个插件同步升至 `0.2.5`，避免同版本安装缓存沿用旧 bundle；共享样式由两包分别打包。

验证：`pnpm check`、48 项测试、`pnpm build`、`pnpm run pack` 通过，包内 manifest 版本均核对为 `0.2.5`；另外实际 Memos 组件的 React test renderer 合成回归通过（仅测试目录外临时依赖）。运行环境为 Node 24.22.1 / pnpm 11.25.0，不替代 README 要求的 Node 22+ / pnpm 9 与官方 DSH 验收。CSS 经 esbuild 解析通过。实际浏览器启动此前受执行沙箱限制，本轮未重试，未生成正式界面截图。未安装、部署或修改真实账户数据。

已加载记录的搜索/排序不是全量服务器搜索；项目 chips 也仅由已发现的服务器项目构成。本地草稿不是离线同步。插件需要本仓库当前 FastAPI API，不能与旧版 DogO 服务混用。
