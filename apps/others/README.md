# Others

服务器侧工具及配套服务，不代表必须部署一个统一后端或服务器 Agent。

按需要分别实现：

- 工具服务：通过 MCP 等接口暴露受授权的服务器工具与数据。
- 消息中转：转发任务、回执、进度、审批与结果，不自主决定执行任务。
- 信息同步：同步约定范围内的个人信息及项目概要，不承担 Agent 推理。

三类能力可以独立部署、使用不同服务，或复用外部实现；不要求全部自建。
已新增 [services](services/README.md)：任务信箱、MCP 工具、持久事件通知与共享记忆文件夹同步原型。
任务与记忆模块可按配置单独启用、分开部署；父目录包仍仅为分组占位。
不在仓库保存服务器凭据、个人数据或真实部署密钥。
