# @dogo/runtime

独立 Node.js 24+ 进程；当前使用 ESM JavaScript 实现执行边界，渲染侧接口有 TypeScript 类型。
管理官方 `@deepseek-ai/dsh@0.2.0-rc.2` Web 后端子进程，任务及配置存 SQLite，原生会话存 DSH。Pi Coding Agent 依赖及执行模块已移除。

## 已实现

- stdio JSON-lines RPC：snapshot/configure/create/followup/cancel；目录授权只由 Electron 原生对话框触发。
- 真实只读目录检查；DSH 对话、流式输出、受限源码读取、停止、会话恢复及错误传播。
- 单任务串行执行；完整退出停止任务；意外退出标记 interrupted，不自动重试。
- 本机 HTTP OpenAI 兼容模型地址；不读取旧 Pi/DSH/Codex 配置或环境中的 API key。
- DogO 只读 preset 不装项目指令、技能、shell/write 工具；隔离会话工作目录，仅按需读取显式授权源码。原生 DSH 新会话的权限单独由 DSH 管理。
- 独立 `dsh/` 数据目录，不覆盖 `~/.dsh`。DSH 原生界面通过 `openDsh` 原生桥接打开。
- 新 profile 安装 Codex 订阅和工作目录记忆插件；登录由用户完成，不复制凭据。现有 profile 的用户改动不被重新初始化覆盖。

只读文件工具限制在显式授权目录：拒绝目录逃逸、符号链接、隐藏文件、常见凭据文件名、二进制文件；
每文件最多 64 KiB、每轮最多 12 次读取。目录列表最多 350 项、4 层。
过滤不保证发现所有敏感信息；用户仍需选择适合供本地模型读取的目录。不是 OS 级不可信代码沙箱。
每轮最多 32 次模型轮转、20 分钟、512000 字符；保留部分结果。达到模型输出上限明确报错，不伪装完整回答。
启用 DSH 自动压缩：窗口压力阈值 75%，额外余量最多 2048 token、保留比例 16%、摘要最多 2048 token；实际阈值还受输出预留约束。真实长上下文仍需专项验证。

```sh
pnpm test:runtime
```

测试使用临时目录及本机模拟模型；覆盖权限、持久化、中断、取消、真实 DSH 工具调用/跨进程恢复、插件加载、HTTP 鉴权/Origin、输出上限和失败状态。
本机路径授权不从旧任务自动恢复。DSH 仅监听 `127.0.0.1` 随机端口；桥接拒绝 Origin、校验 Host 和每次启动的 Bearer。没有开放公网。
`node scripts/smoke-dsh.mjs` 为显式真实本地 27B 测试，只创建/读取临时合成文件。旧 Pi 历史不能续聊，应创建新 DSH 任务。

## 服务器任务适配

`relay.mjs` 在 runtime 内进行 HTTPS 请求，凭据仅由 Electron 原生侧传入，不出现在快照。
每 5 秒轮询分页待办并回传结果；当前客户端不使用 SSE。消费前需人工确认执行类型与本次目录授权。
领取前持久保存 remoteId/executionId/localId，失败重试沿用身份；有本机执行记录时不重复启动。
结果持久回传，失败不阻止其他收件，UI 显示待回传/已确认；异常退出由本机任务状态报告失败而非自动重跑。
远端任务不能本地追加后续轮次，需从发起端新建任务；没有跨端取消/审批协议。
共享记忆文件夹同步独立接入；不直接同步运行中的 SQLite 文件。
